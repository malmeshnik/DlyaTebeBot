# Обробка виграшів колеса фортуни в Telegram боті

## Що додано

Додано обробку кодів виграшу з колеса фортуни в Telegram бот (`bot/tg_bot/handlers/handlers.py`).

## Як це працює

### Флоу для зареєстрованих користувачів:

1. Користувач крутить колесо на сторінці `/miniapp/bonus-wheel`
2. Натискає "Забрати приз у боті"
3. Переходить за посиланням: `https://t.me/DLYA_TEBE_perfumes_bot?start={код}`
4. Бот автоматично:
   - Перевіряє код виграшу
   - Прив'язує приз до користувача
   - Відправляє повідомлення з кодом для касира
   - Позначає приз як забраний

### Флоу для нових користувачів:

1. Користувач переходить за посиланням з кодом
2. Бот просить зареєструватися (надати контакт)
3. Після реєстрації **автоматично активує приз**
4. Користувач одразу бачить своє повідомлення про виграш

## Повідомлення про виграш

```
🎉 Вітаємо з виграшем!

Ви виграли: 20 мл
Ваш код: WABC123XYZ

📍 Покажіть цей код на касі магазину Dlya Tebe, 
щоб отримати свій приз.

💝 Дякуємо за участь!
```

## Помилки

**Невірний або використаний код:**
```
❌ Невірний або вже використаний код.

Можливо, ви вже активували цей приз раніше, або код введено невірно.
```

## Що змінено в коді

1. **Додано імпорти:**
   - `CommandObject` - для отримання параметрів /start
   - `timezone` - для позначки часу активації
   - `WheelSpin` - модель виграшів

2. **Оновлено handler `start`:**
   - Перевіряє чи є параметр (код виграшу)
   - Якщо користувач не зареєстрований - зберігає код в state
   - Викликає `handle_wheel_prize()` для обробки

3. **Додано функцію `handle_wheel_prize()`:**
   - Перевіряє код в базі даних
   - Прив'язує виграш до telegram користувача
   - Позначає як забраний (`is_claimed=True`)
   - Відправляє красиве повідомлення

4. **Оновлено `handle_contact`:**
   - Після реєстрації перевіряє чи є збережений код
   - Автоматично активує приз для нового користувача

## Логування

Всі дії логуються:
- ✅ Успішна активація призу: `User {id} claimed prize {name} with code {code}`
- ⚠️ Невірний код: `User {id} tried invalid code: {code}`
- ❌ Помилка: `Error handling wheel prize: {error}`

## Тестування

**Локально:**
1. Створіть тестовий виграш в адмінці
2. Отримайте код (наприклад: `WABC123XYZ`)
3. Відправте в бот: `/start WABC123XYZ`

**Production:**
1. Прокрутіть колесо на `https://your-domain.com/miniapp/bonus-wheel`
2. Натисніть "Забрати приз у боті"
3. Перевірте що бот відправив повідомлення з кодом

## Перезапуск бота

Після змін **обов'язково перезапустіть бот**:

```bash
# Якщо через Docker:
docker-compose restart backend

# Якщо локально:
# Ctrl+C та запустіть знову
```
